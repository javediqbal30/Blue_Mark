Blue Mark Advisory — Hostinger upload

Upload the CONTENTS of this ZIP into public_html, keeping assets/ and all page folders. Do not upload the enclosing ZIP folder as a nested directory. Open index.html for the home page.

Home voice attempts automatic playback; most browsers block speech without a user gesture. The Play presentation button is provided on every page. Voice uses the visitor browser and system voices.

The contact form opens a pre-filled email in the visitor email client. Email and WhatsApp links work without a server backend.

The source supplied only excerpts and titles of blog posts, so blog cards contain summaries rather than invented full articles. Branding is typographic because original logo image bytes were not supplied.

Services and marketing wording were adapted from the supplied pages. Review regulated-service claims and current filing requirements before publishing.

The updated design uses the supplied blue / white / orange-red ink image. Animations include moving presenter, speaking bubbles, page transitions, heading motion, scrolling reveals, parallax, marquee, progress indicator, hover feedback and intro loader. Browser autoplay policies may prevent speech until a click; this cannot be overridden by site code.
